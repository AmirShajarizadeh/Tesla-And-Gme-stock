# دستیار لایحه‌نویسی برای Claude

پیش‌نویس لایحه با استناد به **قوانین معتبر** (سامانه ملی قوانین، qavanin.ir) و در صورت درخواست **رأی‌های مشابه** (سامانه ملی آرای قضایی، ara.jri.ac.ir).

## اجزا

| بخش | کار |
|---|---|
| `skills/layehe-nevisi/` | مهارت (Skill): روند کار، قالب انواع لایحه، چک‌لیست ایرادات و مهلت‌ها، قواعد راستی‌آزمایی استنادها |
| `legal-mcp/` | سرور MCP خودمان، با یک مرورگر بی‌صفحه روی کامپیوتر شما: **قوانین** (جستجو، خواندن ماده به ماده، متن در تاریخ مشخص، اصلاحات، آرای وحدت رویه و نظرات مشورتی مرتبط) و **رأی‌ها** (جستجوی دادنامه‌های منتشرشده و خواندن کامل هر رأی) |

**چرا روی کامپیوتر خودتان؟** این سایت‌ها معمولاً فقط به اینترنت داخل ایران جواب می‌دهند. سرورهای MCP در Claude Desktop و Claude Code روی کامپیوتر شما اجرا می‌شوند، پس از اینترنت شما استفاده می‌کنند. **VPN را خاموش کنید** (یا فقط برای Claude روشن بگذارید و برای این سایت‌ها از پراکسی ایرانی استفاده کنید، پایین را ببینید).

> نسخه وب و موبایل claude.ai نمی‌تواند سرور محلی اجرا کند؛ مهارت در آن‌ها کار می‌کند ولی بدون ابزارهای جستجو.

## پیش‌نیازها (یک بار)

1. **uv**: ابزار اجرای Python. ویندوز (PowerShell):
   `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`
   مک/لینوکس: `curl -LsSf https://astral.sh/uv/install.sh | sh`
2. **مرورگر**: Google Chrome یا Microsoft Edge نصب باشد کافی است. اگر نیست: `uvx playwright install chromium`
3. این پوشه (`layehe-assistant`) را روی کامپیوتر خود داشته باشید.

## نصب در Claude Code

```bash
claude plugin marketplace add /path/to/layehe-assistant
claude plugin install layehe-assistant@layehe
```

یا برای آزمایش سریع: `claude --plugin-dir /path/to/layehe-assistant`

## نصب در Claude Desktop

1. **ابزارها**: Settings ← Developer ← Edit Config و محتوای `desktop/claude_desktop_config.example.json` را اضافه کنید. مسیر `legal-mcp` را با مسیر واقعی روی کامپیوترتان عوض کنید. Claude Desktop را کامل ببندید و باز کنید.
2. **مهارت**: `python desktop/make_skill_zip.py` (یا از فایل آماده `desktop/layehe-nevisi.zip` استفاده کنید) و در Settings ← Capabilities ← Skills آن را بارگذاری کنید.

## اولین آزمایش

در Claude بنویسید:

> ابزار ara_diagnose را اجرا کن.

اگر همه `ok: true` بودند، آماده است. اگر نه، پیام خطا راهنمایی می‌کند. فایل‌های HTML ذخیره‌شده در `~/.legal-mcp/snapshots` را برای توسعه‌دهنده بفرستید تا تجزیه‌گر دقیق‌تر شود.

بعد مثلاً:

> موکل من خوانده دعوای مطالبه وجه چک است. چک در سال ۱۳۹۸ صادر شده و خواهان دارنده با ظهرنویسی است، ولی ظهرنویسی بعد از برگشت خوردن چک انجام شده. یک لایحه دفاعیه برای دادگاه عمومی حقوقی بنویس و چند رأی مشابه هم پیدا کن.

## تنظیمات اختیاری (متغیرهای محیطی در بخش `env` پیکربندی)

| متغیر | کاربرد |
|---|---|
| `LEGAL_MCP_PROXY` | پراکسی برای رسیدن به سایت‌ها، مثل `http://127.0.0.1:8080` |
| `LEGAL_MCP_BROWSER` | مسیر مرورگر Chrome/Edge اگر خودکار پیدا نشد |
| `LEGAL_MCP_ARA_SEARCH_URL` | نشانی مستقیم جستجوی آرا با `{query}` و `{page}`؛ اگر خالی باشد، عبارت در کادر جستجوی سایت تایپ می‌شود |
| `LEGAL_MCP_HEADLESS=0` | نمایش پنجره مرورگر برای عیب‌یابی |
| `LEGAL_MCP_EXTRA_SITES` | دامنه‌های مجاز بیشتر برای `legal_read`، جداشده با ویرگول |

## وضعیت و محدودیت‌ها

- `legal-mcp` بدون دسترسی زنده به سایت‌ها نوشته شده است (از خارج ایران در دسترس نبودند) و روی صفحه‌های نمونه آزموده شده. اگر ساختار صفحه‌ای شناخته نشود، ابزار به‌جای خطا متن صفحه (`page_text`) را برمی‌گرداند. اولین اجرای واقعی با `ara_diagnose` و `pytest -m live` مشخص می‌کند کجا تنظیم دقیق‌تر لازم است.
- همه کد را خودمان نوشته‌ایم و به هیچ بستهٔ دیگری با محدودیت مجوز وابسته نیست.
- خروجی پیش‌نویس است و باید پیش از ثبت توسط وکیل بازبینی شود.

## توسعه

```bash
cd legal-mcp
uv run --group dev pytest          # آزمون‌های آفلاین
uv run --group dev pytest -m live  # آزمون زنده (فقط از اینترنت ایران)
```
