# ara-mcp

Read-only MCP server for Iranian court rulings (سامانه ملی آرای قضایی، ara.jri.ac.ir) and pages of official legal
sites, through a local headless browser (Playwright, using installed Chrome/Edge when available).

Tools: `ara_search`, `legal_read`, `ara_diagnose`. Run with `uv run ara-mcp`. See the parent README for setup.
