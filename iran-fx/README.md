# حباب دلار با درهم و تتر

درهم به دلار پِگ است (`1 USD = 3.6725 AED`)، پس:

```
دلار ضمنی درهم = قیمت درهم (تومان) × 3.6725
حباب دلار     = دلار بازار ÷ دلار ضمنی درهم − 1
حباب تتر      = تتر ÷ دلار ضمنی درهم − 1
```

این عدد «حباب نسبت به ارزش ذاتی» نیست؛ فاصلهٔ دو کانال ارزی داخلی است.
مثبت بزرگ = دلار نسبت به درهم گران (هیجان / تقاضای خبری)، منفی = دلار عقب مانده.

## اجرا (روی سیستم خودت در ایران؛ منابع از IP خارجی باز نمی‌شوند)

```bash
pip install requests pandas
python fx_bubble.py live --log data/fx_log.csv          # لحظه‌ای: tgju + نوبیتکس/والکس
python fx_bubble.py manual --aed 28150 --usd 104500 --usdt 105200
python fx_bubble.py history data/fx_daily.csv --window 20 --out reports/bubble.csv
```

- `live --log` را مثلاً هر ۱۵ دقیقه با cron اجرا کن تا تاریخچهٔ خودت ساخته شود.
- فایل history: ستون‌های `date,usd,aed,usdt` به تومان (مثلاً خروجی جدول tgju).
- ستون `*_bubble_z` نشان می‌دهد حباب امروز نسبت به میانگین ۲۰ روزه چند انحراف معیار فاصله دارد.
- آستانه‌های `HIGH_BUBBLE` و `LOW_BUBBLE` پیش‌فرض‌اند؛ قبل از استفاده بک‌تست کن.
- ساختار پاسخ APIها از خارج ایران تست نشده؛ اگر منبعی خطا داد، تابع مربوطه در `fx_bubble.py` را اصلاح کن.
